rosbridge is not running? Start it here

This page talks to ROS 2 over a rosbridge websocket on ws://localhost:9090. Install the bridge once, then launch it alongside your exploration stack.

# install (match your distro, e.g. humble / iron / jazzy)
sudo apt update && sudo apt install ros-$ROS_DISTRO-rosbridge-suite

# launch the websocket server (keep this terminal open)
source /opt/ros/$ROS_DISTRO/setup.bash
ros2 launch rosbridge_server rosbridge_websocket_launch.xml
# → listening on ws://0.0.0.0:9090

# sanity check that the topics are live
ros2 topic echo /auction_clock --once
ros2 topic echo /active_frontier --once

Open this file straight from disk (file://) or serve it with python3 -m http.server — either works, since the bridge is on the same machine. To point at another host, append ?ws=ws://192.168.1.20:9090 to the URL.
