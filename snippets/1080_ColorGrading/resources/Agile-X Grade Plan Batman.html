Agile-X unboxing: grade plan

Same nine nodes, now for daytime footage. The reference clip is a night scene, so only its color style is copied: red-orange shadows that turn amber and then cream toward the highlights, with almost no blue in the darks. Brightness and contrast follow a daylight tone curve instead, so rooms, faces and the robot stay readable.

What is taken from the reference, and what is not

I measured 58 frames of the reference (1.5 fps, letterbox bars excluded, decoded as Rec.709) and grouped the pixels by their brightness. That shows how color behaves from dark to bright regardless of what was in front of the camera.

What changed from v2. v2 matched the reference's night histogram, which crushed daylight faces and the arm to black. v3 keeps the hue path and saturation profile and replaces the crush with a daylight tone curve. Nodes 03, 04, 05, 06, 07 and 09 have new values. Nodes 01, 02 and 08 are as before.

Node by node

The manual defines the controls, not the numbers, so confirm each step against the checks in the next section.

06

Look · warm daylight

Group Post-Clipchanged

The whole style in one node, as per-channel lift, gain and gamma in DaVinci Intermediate (Primaries ▸ Bars). I fitted them so a neutral grey ramp follows a daylight tone curve and the reference's hue path and saturation profile. Pick one strength. The values follow standard lift, gain and gamma math on DaVinci Intermediate code values, y = (gain · (x + lift · (1 − x)))^(1/γ). Resolve's own readouts can scale Gamma differently, so the check in the next section is the authority, and the LUT files carry the exact same transfer.

LUT alternativeAgileX_Look_Daylight_Recommended_DI_1D.cube (and _Full, _Subtle)Right-click the node ▸ 1D LUT. First copy the file to the LUT folder with Open LUT Folder and Update Lists in the Lookup Tables panel of Project Settings (manual ch. 150). Then leave Lift, Gain and Gamma at their defaults.

Reading the numbers: Lift pulls blue down hardest, so the darks keep mostly red and amber. Green and blue gamma sit at 0.50, which holds them low through the midtones, and only red keeps gamma near 1. All three channels converge near the top, so highlights end in cream rather than white.

How close the fit is. Against the target curve (daylight tone curve plus 80% of the reference chroma) the fit is off by 2 points on average and 7.7 at worst, on a 0–100 scale. Clipped lights at 100% input come out yellower (60°) than the reference's brightest pixels (43°). Hue in the first few percent of the range is noisy and not worth chasing. Order of work

  1. Create the group. Build nodes 01 and 02 in Group Pre-Clip, and nodes 06 to 08 in Group Post-Clip. Enter the Recommended values in node 06 first.
  2. Pick a well-lit shot with the presenter. Grade node 03 until skin and the white wall hit the pre-look targets.
  3. Run the grey-ramp check on a wall patch. Trim node 06 until the parade matches the table.
  4. Look at skin and the cabinets. If they read too orange, switch to Subtle. If the style feels timid, switch to Full.
  5. Build node 04 on the hero shot, save it as a shared node and lock it.
  6. Walk the other shots and rebalance only node 03. Compare against a saved still of the hero shot in split screen.
  7. Add node 05 to the robot shots, then set Halation and the vignette in node 07 while looking at a bright light source.
  8. Check noise on the darkest shot at 100% zoom, then set grain and blanking in node 09.
