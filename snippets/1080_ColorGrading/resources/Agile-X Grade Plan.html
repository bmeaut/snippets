DaVinci Resolve 20 · Color page · Sony A7 III, PP5 · 20 mm f/1.8

Agile-X unboxing: grade plan

A nine-node tree that takes the dark, slightly warm, orange-heavy office footage to a clean, neutral-white, steel-cool look with natural skin and a robot arm that reads against black foam. Four levels do the work: group Pre-Clip, Clip, group Post-Clip and Timeline.

What the sample shows

I pulled frames from your clip and measured them. The sample is a 720×1280, 8-bit, 25 fps H.264 file, so read the numbers as relative and re-check them with scopes on the original A7 III files.

About PP5. Sony's help page for the A7 II lists PP5 as the Cine1 gamma sample. I could not confirm the A7 III list, and profiles can be edited, so check PP5 in the camera menu. Cine1, Cine2, Movie and ITU709 all use Rec.709 primaries, so the 709 input in this plan fits them. If the camera shows an S-Log gamma, use S-Gamut3.Cine / S-Log3 (or the matching S-Gamut and S-Log2) as the input in node 02 instead.

The node graph

Everything is serial, so each node sees the result of the one before it. Resolve applies the levels in a fixed order: Pre-Clip, Clip, Post-Clip, then Timeline (manual pp. 3304, 3324). I used no parallel or layer mixers because nothing here needs overlapping blends. Add one only if you want a glow built from a blurred copy of the highlights.

Node by node

Starting values are mine. The manual defines the controls and the method, not the numbers, so judge every value on the waveform, vectorscope and a calibrated viewer.

01

NR · denoise

Group Pre-ClipStudio

Noise reduction goes first so the lift in node 03 does not amplify noise. In one node, Resolve processes noise reduction before color adjustments (manual p. 3453). A group node is a baseline for every shot. If the darkest shots need more, add a Clip node with extra Spatial NR on a shadow qualifier.

Control (Color ▸ Motion Effects)StartCheck
Temporal NR frames2, Motion Est. Better, Range MediumStill areas clean, the moving hands do not ghost.
Temporal Luma / Chromaungang, Luma ≈ 3, Chroma ≈ 8Raise slowly until static noise drops. Chroma blotches are usually worse than luma noise in dark 4:2:0.
Motion Threshold50 (default)Lower it if hands leave trails.
Spatial NR modeUltraNR, then Analyze on a flat wall patchUse Show Patch to move the sample box off texture.
Radius / NR BlendMedium / ≈ 25Blend 0 is full effect and 100 is none. Keep some original texture so skin does not turn waxy.
02

CST in · Rec.709 to DaVinci Wide Gamut

Group Pre-Clip

Resolve FX ▸ Color ▸ Color Space Transform. It moves the picture into DaVinci Wide Gamut / DaVinci Intermediate, a log working space where Offset, Log wheels and Contrast with Pivot behave predictably (manual pp. 236–238, 3470). Being a group node, it also covers clips you add to the group later.

ControlValueCheck
Input Color Space / GammaRec.709 / Gamma 2.4Cine1 is a display-referred in-camera curve. Treating it as Gamma 2.4 means it looks as shot until you grade. If it looks wrong next to the source, try Rec.709 (Scene) and use the same choice consistently.
Output Color Space / GammaDaVinci Wide Gamut / DaVinci IntermediateNode 08 is the exact reverse.
Tone Mapping / Gamut MappingNone / NoneGoing from a small gamut into a large one needs no compression.
Testenable only 02 and 08The image should match the raw clip. Any difference means the in and out settings do not mirror each other.
03

Balance · exposure and white balance

ClipRemote version

The only node you rebalance shot by shot. Use Remote versions so every cut from one long take inherits it, including a 16:9 timeline and a 9:16 cutdown made from the same files. Switch an individual clip to a Local version when one cut needs its own fix. Because auto white balance drifts, keyframe the white balance across a change or split the clip.

Control (Primaries)StartCheck
White balanceeyedropper on the wall or a ceiling tile, then trim with the Offset color wheelNeutrals sit on the vectorscope center. Temp up is warmer and Tint up is magenta (manual p. 3063), so a magenta-warm wall needs a small step down on both.
ExposureOffset master wheelSkin at 55–62% on the waveform (the sample cheek is about 27%). In DaVinci Intermediate one stop is about 0.073 in code value, and 18% grey sits at 0.336.
Black pointLift, or Contrast with PivotFoam and shirt at 3–5%, never crushed to 0, so the arm keeps its outline.
Contrast / Pivot1.10–1.20 / start 0.336Nudge Pivot until skin stops moving when you change Contrast.
Highlights / Shadows−10 to −25 / +10 to +20Ceiling panels and window light stay under 92–95%. Watch noise when opening shadows.
Saturation50 → 55–60Cine profiles come out muted.

Wood and skin · Chroma Warp

06

Look · creative color

Group Post-Clip

The stylistic decision, kept out of the clip nodes. A client change here updates every shot in the group at once. The target palette is graphite, white and steel-blue, with warmth only in skin and cardboard.

ControlStartCheck
Log wheels, Shadowsnudge toward blue-cyan, smallCool shadows without a visible tint on the wall. Highlights stay neutral and midtones stay untouched, so skin holds.
Contrast1.05–1.10Crisp, not crushed. The arm must still separate from the foam.
Saturation / Color Boost52–58 / +5 to +10Color Boost lifts low-saturation areas more than saturated ones (manual p. 3063), which wakes up the muted room without pushing the wood.

07

Finish · detail and edges

Group Post-Clip

Clarity, sharpening and a vignette for the 20 mm edges. Each effect is kept small because the footage was lifted a lot.

ControlStartCheck
Midtone Detail+10 to +15Adds definition and also adds noise, so stop early.

Vignettelarge soft ellipse Power Window, inverted, Gain ≈ 0.85–0.90Barely visible. If you notice it, it is too strong.
08

Group Post-Clip

The exact reverse of node 02, placed last in the group rather than in the Timeline grade. The Timeline grade applies to every clip in the timeline (manual p. 3327), including footage that never went through node 02, such as other cameras or graphics.

Order of work

  1. Create the group, then build nodes 01 and 02 in Group Pre-Clip and nodes 06 to 08 in Group Post-Clip with neutral values.
  2. Pick one well-lit shot with the presenter and the arm. Grade node 03 until skin and wall hit the targets above.
  3. Build node 04 on that shot, save it as a shared node and lock it.
  4. Judge the look in node 06 on that hero shot, then check it on a dark wide shot to make sure it still holds.
  5. Walk the other shots and rebalance only node 03. Use split screen against a saved still of the hero shot.
  6. Add node 05 to the robot close-ups.
  7. Check noise on the darkest shot at 100% zoom, adjust node 01, then set node 09.
  8. Run the CST test from node 02 once more before you render.
