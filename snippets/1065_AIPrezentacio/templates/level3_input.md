# 3. szintű teszt-bemenet: táblázatos/számszerű adat + képlet

Téma: napelem-rendszer megtérülése, kisvállalkozói/családi ház nézőpontból. Ez a teszt kifejezetten a Kristóf-féle visszajelzés ("interakció, programozottabb dolog, pl. adatsor betöltése interaktív diagramba") miatt készült, plusz kép és LaTeX-képlet is bekerül.
