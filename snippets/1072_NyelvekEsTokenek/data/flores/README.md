# FLORES-200 devtest (részlet)

Az `eng_Latn`, `hun_Latn`, `deu_Latn` és `jpn_Jpan` nyelvi fájlok a FLORES-200 `devtest` részéből származnak (1012 mondat nyelvenként, a négy fájl sorai egymásnak megfelelő mondatok).

- Forrás: Meta (NLLB Team), FLORES-200 dataset, `https://dl.fbaipublicfiles.com/nllb/flores200_dataset.tar.gz`
- Licenc: Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0). Az adatokat változtatás nélkül, szó szerint tartalmazza ez a mappa.
- Hivatkozás: NLLB Team et al., "No Language Left Behind: Scaling Human-Centered Machine Translation", 2022.
